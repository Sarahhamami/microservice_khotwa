# KHOTWA – Intelligent E-learning Platform 📚🚀

KHOTWA is a modular e-learning platform designed with scalability, flexibility, and user experience in mind. It leverages **microservices architecture** and integrates key services like **Eureka** for service discovery and **API Gateway** for routing and security. Developed using modern web technologies including **Spring Boot**, **Angular**, and **Python**, KHOTWA aims to deliver a personalized, interactive, and high-performance online learning experience.

---

## 🔧 Tech Stack

- **Frontend:** Angular
- **Backend:** Spring Boot & Python
- **Service Discovery:** Eureka
- **API Gateway:** Spring Cloud Gateway
- **Security:** JWT, OAuth2, Keycloak
- **Databases:**
  - H2 (User Management)
  - MySQL (Other services)

## 📌 Features

### ✅ User Management
- Registration/Login via Email, Google, Socials
- Password Reset
- Role-based Access (Admin, Trainer, Student)
- User Profiles with certificates and history

### 📚 Course Management
- Create & organize courses
- Add quizzes and certifications

### 📺 Events & Webinars
- Live sessions with registration and replays
- Post-event evaluations

### 💬 Communication Tools
- Private messaging
- Course discussions and feedback

### 💳 Monetization
- Subscription Plans (Monthly/Yearly)
- Stripe/PayPal integration
- Promo Codes & Invoicing

---

## 🏗️ Architecture

- **Microservices** communicate through Eureka
- **API Gateway** handles routing and authentication
- Services are loosely coupled and can be scaled independently
